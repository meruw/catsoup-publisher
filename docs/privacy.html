This policy describes the Windows version of CATsoup Publisher distributed by the CATsoup Publisher project.

What Publisher stores on your computer

The workspace stores your draft titles, captions, hashtags, file references and hashes, language assignments, platform account IDs and display names. Upload receipts may include the provider’s video or transfer ID. Publisher encrypts saved user access and refresh tokens with Windows Data Protection for the current Windows user. Drafts and receipts are stored locally in SQLite. Developer app configuration is also encrypted with Windows Data Protection and stored separately in your Windows application data folder.

Optional TikTok browser preparation keeps dedicated Chrome profiles and verified usernames in %LOCALAPPDATA%/CATsoup Publisher/browser-profiles/tiktok/. Chrome manages its own session cookies and local storage. The browser sends the chosen video and caption to TikTok Studio; you click Publish there. These sessions are separate from your everyday browser profile. Close Publisher and its dedicated Chrome windows before deleting this folder to erase their sessions. Removing a connection in Publisher does not sign the browser out.

Connection diagnostics are stored locally in %LOCALAPPDATA%/CATsoup Publisher/logs. They contain timestamps, service and language, random attempt identifiers, connection stages, elapsed times and numeric error codes. They exclude tokens, authorization codes, usernames, callback URLs and raw platform responses. Diagnostic logs are not sent to the project automatically; copying or exporting them is your choice.

What goes to a platform

If you enable temporary HTTPS uploads for Instagram, Publisher shares only the approved, prepared MP4 through Cloudflare while Meta downloads it. Anyone with the random link can read that video while active. The local server exposes no directory, credentials or application API. Publisher closes the link on completion, error or cancellation, with a maximum lifetime of 15 minutes. The URL is not stored in receipts or diagnostic logs. This opt-in setting applies to both languages and is separate from OAuth callback hosting.

Sign-in opens the provider’s website. Publisher exchanges the resulting authorization code for access and requests the identity of the connected account. For TikTok it uses basic profile access to identify the account. When you confirm a transfer, Publisher sends the selected video to TikTok and checks processing. Inbox uploads are completed in TikTok; optional Direct Post sends your editable caption, explicitly selected privacy and disclosure settings. Other connected platforms receive the media and applicable metadata required for the action you choose. Opening the X composer sends the prepared post text to X in your browser. Loading post statistics sends the saved media identifier and account authorization to YouTube or Meta and reads available counters. These counts remain in memory while the detail is open; Publisher does not upload them to a CATsoup server or store a metrics history.

For Facebook sign-in, Meta returns a short-lived authorization code and state to the HTTPS return page selected in Publisher. Browser sign-in starts disabled. If you explicitly enable the CATsoup-hosted return page after its notice, GitHub Pages receives the callback URL. If you choose a self-hosted return page, your chosen host receives that request instead. The return page clears that URL from the visible browser history and forwards an encrypted response to the desktop app on this computer. A temporary pairing key is held in this browser tab. The app secret and access tokens are never sent to this site. The desktop app has no CATsoup-hosted account service. The project's maintainers do not receive a copy of your local drafts, videos or tokens as part of sign-in or upload. GitHub hosts the public project pages and applies its privacy statement to visits.

Retention and deletion

Diagnostic files rotate at 10 MB with at most five backups and a seven-day retention policy. Cleanup runs on rotation, at startup and daily while the app runs. Close Publisher and delete its logs folder to clear diagnostics immediately. Copies you export are not automatically deleted.

In Accounts, choose the platform and language and select Remove to delete the saved connection from your workspace. To revoke the grant itself, use the provider’s connected-app settings. Drafts and receipts remain until you delete the local data. To erase all Publisher drafts, receipts and connections in a workspace, close Publisher and remove its data/publisher/ folder. This also removes data for other languages and platforms in that workspace. Manage backup copies and downloaded credentials separately. Delete posted or uploaded content through the platform.

Questions

For a general question about this policy, use project issues. This is a public channel. Keep credentials, private videos and personal account information out of reports.
