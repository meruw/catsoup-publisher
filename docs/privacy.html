This policy describes the Windows version of CATsoup Publisher distributed by the CATsoup Publisher project.

What Publisher stores on your computer

The workspace stores your draft titles, captions, hashtags, file references and hashes, language assignments, platform account IDs and display names. Upload receipts may include the provider’s video or transfer ID. Publisher encrypts saved user access and refresh tokens with Windows Data Protection for the current Windows user. Drafts and receipts are stored locally in SQLite. Developer app configuration is stored separately in your Windows application data folder.

What goes to a platform

Sign-in opens the provider’s website. Publisher exchanges the resulting authorization code for access and requests the identity of the connected account. For TikTok it uses basic profile access to identify the account. When you confirm a transfer, Publisher sends the selected video to TikTok and checks its processing status so you can finish posting in the TikTok inbox. Other connected platforms receive the media and applicable metadata required for the action you choose. Opening the X composer sends the prepared post text to X in your browser.

For Facebook sign-in, Meta returns a short-lived authorization code and state to the HTTPS return page selected in Publisher. The default is this GitHub Pages site. Its hosting provider receives the callback URL. If you choose a self-hosted return page, your chosen host receives that request instead. The return page clears that URL from the visible browser history and forwards an encrypted response to the desktop app on this computer. A temporary pairing key is held in this browser tab. The app secret and access tokens are never sent to this site. The desktop app has no CATsoup-hosted account service. The project's maintainers do not receive a copy of your local drafts, videos or tokens as part of sign-in or upload. GitHub hosts the public project pages and applies its privacy statement to visits.

Retention and deletion

In Accounts, choose the platform and language and select Remove to delete the saved connection from your workspace. To revoke the grant itself, use the provider’s connected-app settings. Drafts and receipts remain until you delete the local data. To erase all Publisher drafts, receipts and connections in a workspace, close Publisher and remove its data/publisher/ folder. This also removes data for other languages and platforms in that workspace. Manage backup copies and downloaded credentials separately. Delete posted or uploaded content through the platform.

Questions

For a general question about this policy, use project issues. This is a public channel. Keep credentials, private videos and personal account information out of reports.
